# CLAUDE.md

Working rules for this repository. Read `docs/DESIGN.md` first. It is the contract.

## What this is

Reckon reconciles bank credits against payment gateway settlements and invoices, and its
product is knowing when to refuse. Precision on auto decided records is the number that
matters. Coverage is a dial set against it, never chased.

## Hard rules

1. **Money is never a number.** Use `Money` from `src/money`. No `number` in any money
   position, no floats, no arithmetic outside the module. If you find yourself wanting a
   raw value, you want `format()` at a display edge, and nowhere else.
2. **Every record ends in exactly one of `MATCHED`, `REVIEW`, `REFUSED`.** No fourth
   state, no default, no silent pass through. A function that can return neither of the
   three is wrong.
3. **The model does not match.** Tiers 1 to 3 are deterministic. Tiers 4 and 5 handle the
   ambiguous residue only. Do not move deterministic work into a prompt because a prompt
   is faster to write.
4. **Never tune against the test split.** `eval/fixtures/test/` is opened once, at the
   end. If you need to look at data, look at dev.
5. **No credentials, no real identifiers, no customer data.** See `docs/REDLINES.md`.
6. **Every published number comes from `npm run eval`.** If a number in the README cannot
   be regenerated by that command, it does not go in the README.

## Layout

```
src/money/       branded Money type. The only place money arithmetic exists
src/ingest/      source parsers, dedupe, completeness check
src/normalise/   canonical record shapes
src/match/       tier1 exact, tier2 bundle, tier3 candidates,
                 tier4 adjudicator, tier5 verifier, gate
src/audit/       append only decision log
src/report/      builds report/index.html
eval/generator/  seeded corpus with ground truth
eval/fixtures/   dev and test splits, committed
eval/cache/      committed model responses, so results reproduce with no API key
docs/decisions/  numbered ADRs
```

## Commands

```
npm run typecheck     tsc, no emit
npm test              node --test
npm run gen:dev       regenerate the dev split from seed
npm run eval          full pipeline over dev, writes metrics
npm run eval:test     the held out split. Run once, at the end
npm run report        build report/index.html from the last run
```

## Conventions

- TypeScript, ESM, Node 22 or newer. Native type stripping, no build step. Type stripping
  is strip only, so parameter properties, enums, namespaces and decorators are
  unavailable and imports carry the `.ts` extension. See `docs/decisions/0004-no-build-step.md`.
- `strict` plus `noUncheckedIndexedAccess` and `exactOptionalPropertyTypes`. Do not relax.
- No dependencies unless there is a written reason. The point of this repo is the
  reasoning, and a dependency that hides the reasoning costs more than it saves.
- Model calls are temperature zero and cached by prompt hash. A new prompt means a new
  cache entry, so changing a prompt invalidates published numbers. Rerun before claiming.
- Commit in small steps that show the build. This repository is read as evidence of how
  the work was done, not only what was produced.

## When a decision is made

Write it as `docs/decisions/NNNN-slug.md` with context, the decision, and what was
rejected and why. A rejected alternative recorded is worth more than a decision asserted.
